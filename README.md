# Арена · Chess Arena

Шахматный тактический баттлер в браузере: фигуры с HP, энергия, способности, боссы и предупреждения об атаках. Победа — уничтожить короля. Сейчас играет локальный алгоритмический бот; Ollama, GPU и Python для игры не нужны.

## Запуск

Нужен Node.js 20 или новее.

```sh
git clone https://github.com/belkovskyy/chess-arena.git
cd chess-arena
npm ci
npm start
```

Открой http://127.0.0.1:4173/. В Windows также можно использовать `Запустить шахматы.bat`. Сервер по умолчанию слушает только localhost. Другой порт задаётся переменной `PORT`.

## Игра

«Новая партия» открывает выбор режима, сложности и шести карт способностей. На каждой фигуре показаны атака и HP. Энергия накапливается по ходу партии; способности расходуют её. Есть ответный урон, защита, лечение, скрытность и атаки по области. Подробные правила и стоимость карт доступны в самой игре.

Три уровня бота: лёгкий допускает ошибки, обычный оценивает удары и способности, сложный глубже проверяет ответы. Сложность не прибавляет HP или урон. Темы «Таверна» и «Шкатулка» переключаются в шапке. Партия и настройки сохраняются локально в браузере.

## Боссы — баланс 14

- **Железный король:** 20 HP, четыре ладьи и четыре пешки. Две соседние ладьи образуют строй: следующий Обвал по области 3×3 наносит 3 урона вместо 2. Можно выманивать охрану и разбирать строй.
- **Колдун:** 16 HP, четыре слона-печати и четыре пешки. Ритуал наносит 3 урона диагональным крестом. Четыре печати дают радиус 3, две-три — 2, ноль-одна — 1. Урон фигуры прерывает подготовку; огонь арены — нет.
- **Охотник:** туман, укрытия, волки, заранее показанный прицел и окно для контратаки после выстрела.
- **Великан:** тело 2×2, каменная кожа, предупреждённые удары, Бросок и Рывок. После удара становится уязвимым.
- **Дед:** пешечная орда с дополнительным рядом пешек.

После объявления область и урон заклинания фиксируются. Потеря печати или разрыв строя ослабляет следующие атаки. Старые сохранения продолжаются на своём движке; для текущих правил нужна новая партия.

## Проверки

```sh
npm test
```

Проверяются строй, печати, исполнение уже объявленной атаки, отмена хода, отражение, прерывание, защита от подделки параметров действия, совместимость прежних режимов и отображение подсказок. GitHub Actions запускает этот набор при push и pull request.

Баланс остаётся экспериментальным. В контрольных автопартиях на сложном Король выиграл 15/16, Колдун 11/16, у Колдуна была одна ничья. Это небольшие детерминированные выборки против тестового бота, не проценты побед человека. Методика и ограничения — [в заметках](docs/balance-14.md).

## Код

- `battle.js`, `encounter-rules.js`, `giant-rules.js` — правила и боссы.
- `bot.js` — выбор ходов и способностей.
- `app.js`, `style.css`, `index.html` — интерфейс.
- `server.js` — локальный HTTP-сервер и API бота.
- `sniper-fx.js` — анимация снайперки.
- `_compat/` — сохранённые движки для старых партий; нужны серверу и интерфейсу.
- `assets/`, `pieces/` — графика. У шахматных SVG есть отдельный [файл лицензии](pieces/LICENSE.txt).

Исторические интеграции LLM сохранены в коде, но текущий экран их не использует. Веса моделей, зависимости, локальные журналы, резервные копии и экспериментальные прогоны не входят в репозиторий. После изменения серверной логики перезапусти `npm start`.
